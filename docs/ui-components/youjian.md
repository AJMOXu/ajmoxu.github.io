# 📧 邮件管控

## 邮件管控策略设置

在选项卡：【高级】->【邮件控制】中设置策略

常见策略有：

1.  <mark style="color:red;">**限制发件人必须为公司邮箱**</mark>\
    该策略需要多条策略同时存在才可生效

    <figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    新建一条<mark style="color:red;">**禁止**</mark>的策略，即<mark style="color:red;">**默认禁止所有**</mark>邮箱发送邮件<br>

    <figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

    再新建一条<mark style="color:$success;">**允许**</mark>的策略，在<mark style="color:red;">**发件人**</mark>中，添加公司邮箱后缀即可<br>
2.  限制收件人必须包含公司邮箱\
    与限制发件人策略相同，该策略也需要多条策略同时存在才可生效<br>

    <figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>

    新建一条<mark style="color:red;">**禁止**</mark>的策略，即<mark style="color:red;">**默认禁止所有**</mark>邮箱发送邮件<br>
